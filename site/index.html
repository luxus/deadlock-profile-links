Deadlock Profile Links

Rank badge and buttons for [Statlocker](https://statlocker.gg/) and [DeadChaps](https://www.deadchaps.gg/) on profile pages, profile cards and the post-game scoreboard.

Add to DMMInstall with DMMDownload VPK

The buttons need Deadlock Mod Manager. Source URL for DMM (Settings → Mods → Mod sources → Add source):
https://luxus.github.io/deadlock-profile-links/dmm-source.json

The same listing is in the shared registry: luxus.github.io/deadlock-mods (https://luxus.github.io/deadlock-mods/dmm-source.json).

Manual install: rename the VPK to a free slot such as pak08_dir.vpk or later and put it into Deadlock/game/citadel/addons/. Slots 01–07 are reserved for CompLock.
